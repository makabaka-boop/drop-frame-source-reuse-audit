# SMPTE 丢帧时码合版核对台

一个不依赖后端 API 的纯前端核对工具，用于检查 29.97 fps（`30000/1001`）和 59.94 fps（`60000/1001`）SMPTE drop-frame 时码合版结果。

## 功能

- 固定输入格式：`HH:MM:SS;FF`，分号明确表示丢帧时码。
- 支持 1–200 个片段，每片包含唯一 `id`、`sourceIn`、`sourceOut`、`recordIn`。
- `sourceOut` 为排他端，时长按整数帧计算：`sourceOut - sourceIn`。
- `recordOut = recordIn + durationFrames`，拒绝零时长、负时长和触碰 24 小时回绕点的录制区间。
- 校验非整十分钟边界的禁用帧：
  - 29.97：`MM:SS;00`、`MM:SS;01`（`MM % 10 !== 0` 且 `SS=00`）不存在。
  - 59.94：`MM:SS;00` 至 `MM:SS;03` 不存在。
- 任一字段或结构非法时拒绝整份输入；页面保留上次合法结果，但标记为非当前结论。
- 重叠按半开区间交集计算：`min(recordOut, 既有覆盖端) - recordIn`。长片包住短片时，短片的重叠就是它自身的帧数，不会延伸到长片结束；表格、色带与导出结果一致。
- SVG 标尺与表格共享同一份分析结果；导出 JSON 直接序列化该结果，不重新计算。
- 标尺刻度严格小于 24 小时回绕点，全日视图和滚动到日末都能正常渲染。
- 数值 id 与字符串 id 可在同批次混用；屏幕上字符串 id 带引号显示（`1` 与 `"1"` 可区分），导出 JSON 保留原始类型。
- 第一处真实空隙或重叠会在摘要、标尺和表格中标出。
- **来源复用审计（只读派生视图）**：把各片段 `[sourceIn, sourceOut)` 投到同一整数来源帧轴，端点扫描生成被至少两片覆盖的最大半开区间。活动片段 id 集合一变即断开，即使复用计数相同也不合并；数值 id 与同字面字符串 id 是不同身份。每段列出来源起止帧及时码、覆盖片段 id，并按各片段自己的 `recordIn` 映射出对应录制区间；点击证据会同时高亮来源段和录制时间线上的全部落点。审计单独下载为 `source-reuse-audit-*.json`，不影响原核对 JSON 导出。
- 来源帧、录制帧都以整数裁决，时码仅作显示；复用审计同样严格位于 24 小时日内，日末边界不回绕。
- 无效编辑按原语义保留两套旧视图，但标记旧接缝结论与复用审计均已过期；新的有效输入会原子替换两套视图。

## 输入示例

```json
{
  "rate": "30000/1001",
  "clips": [
    {
      "id": "A",
      "sourceIn": "01:00:00;00",
      "sourceOut": "01:00:05;00",
      "recordIn": "00:10:00;00"
    }
  ]
}
```

`id` 可以是非空字符串或安全整数，并且在整份输入中必须唯一。未知根字段、未知片段字段、重复 id、非法结构都会导致整份拒绝。

## 丢帧算法

普通换算会把一分钟误算为 1800（或 3600）个标签帧；drop-frame 时码在每个非整十分钟跳过一组帧号：

- 30 nominal：每 10 个标签分钟包含 `10 × 1800 - 9 × 2 = 17982` 个真实帧。
- 60 nominal：每 10 个标签分钟包含 `10 × 3600 - 9 × 4 = 35964` 个真实帧。
- 30 fps 日帧长：`24 × 6 × 17982 = 2589408`。
- 60 fps 日帧长：`24 × 6 × 35964 = 5178816`。

解析时累计 `00:00` 到当前标签分钟之间发生过的非整十分钟数量，再减去对应跳帧数；反算时按十个真实分钟的块进行整数除法，避免浮点和普通时分秒换算错误。

## 测试

`src/lib/timecode.test.ts` 覆盖：

- 整十分钟边界；
- 小时边界；
- 非整十分钟首个合法帧和禁用首帧；
- frame → timecode → frame 与 timecode → frame → timecode 往返；
- 24 小时边界。

`src/lib/analysis.test.ts` 覆盖 recordOut、按录制位置排序、空隙、重叠、完全包含与同一长片内多个短片的半开区间交集、混合类型 id 的身份保持、非法输入拒绝和导出快照。

`src/lib/timeline.test.ts` 覆盖全日缩放、日末滚动及各缩放档位下标尺刻度不触碰 24 小时回绕点。

`src/lib/reuse.test.ts` 用逐帧成员集合预言机覆盖来源复用审计：包含、交叉、三重覆盖的分段、相邻端点（半开不相会）、覆盖计数相同但活动 id 集合变化时的断开、低覆盖帧隔开的两段不合并、数值/字符串混合 id 身份、按各片段自身 `recordIn` 的落点映射、日末来源标签不回绕，以及 300 组随机区间与预言机逐项一致；并断言原核对 JSON 键集合逐项不变、复用报告独立成文。

`src/lib/app.dom.test.tsx`（jsdom）做页面联动验收：点选来源段后来源段与录制时间线全部落点同时高亮、卡片/时间线双向切换与取消、非法编辑保留并标记旧结论过期、新有效输入原子替换两套视图并清空选择、两份下载各自独立。
